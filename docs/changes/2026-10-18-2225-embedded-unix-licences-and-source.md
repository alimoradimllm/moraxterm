# Add licence texts and source pointers for the GPL programs in the bundled Unix runtime

The Windows installer bundles `Moraxterm_EmbeddedUnix_x64_0.1.24.tar.xz` (MSYS2: Fish, Bash, Wget, inetutils, mintty and about 100 more packages). Its own `usr/share/licenses` holds only 25 packages, and only 6 of its 64 copyleft packages, so Fish, Bash, Wget and inetutils had no licence text and nothing pointed to their source. This change adds both in the repository:

- `scripts/embedded_unix_licenses.py` reads the pacman database inside the archive and writes `docs/EMBEDDED_UNIX_PACKAGES.md`: all 101 packages with exact version, SPDX licence, upstream URL, whether the archive ships a licence directory, and the MSYS2 source archive URL at that version.
- `LICENSES/` holds the full texts of GPL-1.0/2.0/3.0, LGPL-2.1/3.0, AGPL-3.0, MPL-2.0, the GCC Runtime Library Exception 3.1 and the PCRE2 exemption, with an index.
- `THIRD_PARTY_NOTICES.md` now states the facts and rewrites the "Open" list.

Verified: the script ran on the archive (SHA-256 `5b21b349…bf582`) and wrote 101 packages; Fish is GPL-2.0-only, Bash, Wget, inetutils and mintty GPL-3.0-or-later. A HEAD request to each of the 85 distinct source archives (every package, not only copyleft ones) returned HTTP 200, 0 failures, 0 unchecked. An earlier run reported most links as failing; that was the server throttling rapid requests, and the script then treated any error as "missing". It now retries, waits between requests, and reports only a real 404 as missing and anything it could not check as "not checked". Each licence file was checked to begin with its expected title and version line and to contain no HTML. The archive holds two package databases (`./msys64/...`, 85 packages, and `./var/...`, 101 packages); the script reads `./var/...`, which is where Fish is. My first count used the wrong one (85 packages, no Fish), which is why I looked.

Open: the texts and source links are in the repository, not yet inside the installer, and I did not check whether the installer includes them. HTTP 200 shows the source files exist on MSYS2's server, not that they match the archive's binaries byte for byte, and Moraxterm does not control that server. A written offer of source, or hosting the source archives with each release, is not done. The licence identifiers for older packages (`GPL`, `GPL3`, `custom`) do not say which version applies. The licence-dir column compares directory names to package names exactly; I checked that all 25 directories in the archive match a package name and that no `no` row has a similarly named directory, so it is accurate for this archive. The archive is untracked, so CI cannot rerun the script; it must be rerun when the archive changes. This records facts from the archive and is not legal advice; a lawyer should review the redistribution before a wide release.
