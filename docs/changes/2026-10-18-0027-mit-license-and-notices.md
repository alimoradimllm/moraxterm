# License the project under MIT and record third-party notices

The repository had no LICENSE file, although the README said one was kept in GitHub metadata, so no license was granted. The owner chose MIT. This adds LICENSE (MIT, copyright Ali Moradi, 2026), CONTRIBUTING.md (contributions are licensed under MIT, how to branch, the per-change docs file, no secrets, disposable servers only), and THIRD_PARTY_NOTICES.md. The README license section now points to them, and the Tauri crate and package.json declare license = MIT (the two other manifests already did). The notices file records, from real checks, that all 53 rust-core crates and 446 of 454 Tauri crates are permissive, that five are MPL-2.0 and two offer an LGPL option, that the npm side has no GPL, and that the Windows installer embeds an MSYS2 runtime whose license texts are incomplete.

Verified: cargo metadata and package-lock.json were read for the dependency counts and the MPL crate names. The archive listing was read with tar -tJf: it holds fish.exe, bash.exe, ssh.exe, curl.exe, wget.exe and telnet.exe, and ships license directories for only 25 packages, none for Fish, Bash, Wget or inetutils. cargo check and the frontend typecheck pass after the manifest edits.

Open: the embedded runtime still lacks license texts for Fish, Bash, Wget and inetutils and a source pointer for its GPL programs, so a wide release of the Windows installer should wait for that. The GPL status of each program is from upstream's known licensing, not read from the archive's own metadata. No full per-release license bundle is generated. The owner name on the copyright line is taken from the GitHub profile. None of this is legal advice.
