# Let each session run the UI tests on its own port, keep open tabs in step with renames, and darken Light-theme icons

The UI test scripts all used one debugging port (9333) and one profile folder, so two Hermes sessions testing at once would drive each other's app, and an earlier version of these scripts stopped every Moraxterm process by name, which could close an app that belonged to someone else. A new scripts/ui_guard.py is now the one place that decides the port and the profile: MORAXTERM_UI_PORT picks the port (default 9333), and any other port gets its own throwaway profile folder (moraxterm-ui-test-<port>) with its own session database and WebView2 data, so sessions never share state. "python scripts/ui_guard.py free-port" prints an unused port. The launcher and the tests refuse to start if their port is already taken, and the tests stop only the exe built in their own worktree, never other copies or the installed app. cdp_driver, the launcher and all five installed-app suites read the port and profile from ui_guard.

Two UI fixes that were listed as open in the previous change: a terminal tab that is already running now takes the new name when its session is renamed (before, it kept the old label), and deleting a session leaves its running tab open. The Light theme icons were hard to see (the pale yellow SSH lock and the Sessions star on white), so the Light theme now darkens the icons more and uses a stronger tint behind them; the tint is a variable (--tint) so the other themes keep their previous look.

Verified: all five installed-app suites passed on a freshly built exe while another Hermes session's app held port 9333: this session ran on port 9340 with its own profile. smoke 9 of 9, MultiExec all pass, folders 24 of 24, import 2 of 2 checks, session actions 28 of 28 (four new checks: a running tab follows a rename, a deleted session leaves its tab open). Port 9333 still had its single listener afterwards and the other session's two Moraxterm processes were still running, so nothing of theirs was touched. The real session database was checked unchanged. A screenshot of the Light theme after the change was reviewed: the SSH lock, the star, Tools and Serial are clearly visible against their tiles.

Open: two sessions can still collide if both leave MORAXTERM_UI_PORT unset, because the default is shared; the guard then stops the second one before it does anything, rather than letting it run. The Amber and Midnight themes were rendered and not reviewed in detail. Light-theme terminal text colours were not checked against real shell output. A tab opened from a session keeps that session's other settings until it is reopened, only the label follows a rename.
