# Add a per-target Stop control to MultiExec

MultiExec could mirror input to several terminals but had no way to end just one of them; the only options were closing the tab or leaving MultiExec. Each live target now has a "■ Stop" button, both in the Targets panel and in its pane bar while MultiExec is on. Stop calls `close_terminal` for that one terminal only. The tab stays open and is marked `exited`, so `mirrorTargets` and `pasteTargets` skip it (they already skipped exited tabs), the banner's target count drops, the panel lists it as "stopped" without a Stop button, and its old sent/failed badge is cleared. Reconnect restarts it and it takes part in mirroring again. `canStop(tab)` in `multiexec.js` (only `starting` or `connected`) decides when the button is enabled. Files: `App.tsx`, `MultiExecManager.tsx`, `multiexec.js`/`.d.ts`, `react-ui.css`, `tests/multiexec.test.mjs`, and the new `scripts/ui_multiexec_stop_test.py`.
